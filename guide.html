GitHub 저장소는 파일을 보관하는 곳이고, GitHub Pages는 그 파일을 웹사이트로 보여주는 기능입니다.

1. 마스터페이지 배포하기

  1. 전달받은 ZIP 파일의 압축을 풉니다. index.html을 더블 클릭하면 먼저 둘러볼 수 있습니다.
  2. GitHub에서 새 저장소 만들기를 엽니다. 이름을 예를 들어 my-webapps로 입력하고, 무료 계정으로 시작한다면 Public을 선택합니다. README 추가 옵션을 켜고 저장소를 만듭니다.
  3. 저장소의 Add file → Upload files를 누릅니다. 압축을 푼 webapp-hub 폴더 안의 파일들과 apps 폴더를 함께 끌어 넣습니다. ZIP 파일이나 바깥쪽 webapp-hub 폴더 자체를 올리지 않습니다.
  4. Commit changes로 저장합니다. 저장소 첫 화면에 index.html, apps.js, style.css, apps 폴더 등이 보여야 합니다.
  5. Settings → Pages → Build and deployment로 이동합니다. Source는 Deploy from a branch, Branch는 main, 폴더는 /(root)로 설정하고 Save를 누릅니다.
  6. 배포가 완료되면 Pages에 표시되는 Visit site를 엽니다. 반영까지 몇 분 걸릴 수 있습니다.
https://내아이디.github.io/my-webapps/

위 주소는 예시입니다. 실제 주소는 GitHub의 Pages 화면에서 확인하세요.

2. 과목별 웹앱 주소 등록하기

스프레드시트에는 과목 · 앱 이름 · 설명 · 배포된 웹앱 주소를 정리하세요. 그중 웹앱 주소를 아래처럼 apps.js의 path에 넣습니다. 구글 시트 문서 주소가 아니라 실제 웹앱 주소를 복사하세요.

{
  name: "우리 반 모의선거 LAB",
  description: "교실에서 함께 진행하는 모의선거",
  category: "사회",
  icon: "VOTE",
  path: "https://alex6401.github.io/Alex/election-lab.html"
}

category는 사회 또는 역사로 입력합니다. 항목 사이에는 쉼표를 넣고 GitHub에서 변경 내용을 저장하세요. 시트만 수정하면 마스터페이지 목록이 자동 변경되지는 않습니다. 같은 저장소의 앱은 election-lab.html처럼 상대 경로로 등록할 수도 있습니다.

아직 웹주소가 없는 HTML 파일은 먼저 업로드하세요

웹앱마다 폴더 하나를 만들면 파일이 섞이지 않아 관리하기 쉽습니다. 예를 들어 계산기 앱이라면:

my-webapps/
├── index.html           ← 마스터페이지
├── apps.js              ← 카드 목록
├── hub.js
├── style.css
├── favicon.svg
├── guide.html
└── apps/
    ├── example/
    │   └── index.html
    └── calculator/
        ├── index.html   ← 내가 만든 HTML
        ├── style.css    ← 필요한 경우
        ├── script.js    ← 필요한 경우
        └── images/      ← 필요한 경우
  1. 내 컴퓨터에서 apps/calculator 폴더를 만들고 만든 HTML을 index.html이라는 이름으로 넣습니다. HTML 하나에 모든 코드가 들어 있다면 그 파일만 있으면 됩니다.
  2. HTML이 사용하는 CSS, JavaScript, 이미지도 원래 폴더 관계를 유지해 함께 넣습니다.
  3. GitHub 저장소에서 apps 폴더를 연 뒤 Add file → Upload files로 calculator 폴더 전체를 올리고 저장합니다. 업로드 화면에서 경로가 apps/calculator/index.html인지 확인하세요.
  4. 저장소 첫 화면으로 돌아가 apps.js를 누른 후 연필 아이콘으로 편집합니다. 아래처럼 목록에 항목을 추가하고 Commit changes로 저장합니다.
window.WEB_APPS = [
  {
    name: "첫 번째 웹앱",
    description: "연결을 확인하는 예제",
    category: "사회",
    icon: "01",
    path: "apps/example/index.html"
  },
  {
    name: "내 계산기",
    description: "직접 만든 계산 도구",
    category: "사회",
    icon: "02",
    path: "apps/calculator/index.html"
  }
];

저장 후 배포가 끝나면 마스터페이지를 새로고침하세요. 새 카드가 나타납니다. HTML 파일만 올리면 카드가 자동 생성되지는 않으므로 apps.js 등록도 필요합니다. 예제 항목은 지워도 됩니다.

3. 수정하거나 삭제하기

  • 앱 수정: 같은 경로의 파일을 수정해 저장하면 다음 배포에 반영됩니다.
  • 목록에서 제거: apps.js에서 해당 항목을 지웁니다. 기존 앱 주소도 없애려면 앱 파일도 삭제합니다.
  • 마스터페이지 이름 변경: index.html의 제목과 화면에 보이는 이름을 바꿉니다.

잘 안 될 때

  • 404: 파일 경로와 대소문자를 확인하세요. Calculator와 calculator는 다릅니다.
  • 화면 모양이나 이미지가 깨짐: 함께 쓰는 파일을 빠뜨리지 않았는지 확인하세요. 프로젝트 사이트에서는 /style.css보다 ./style.css처럼 현재 폴더 기준 경로를 사용하세요.
  • 카드가 사라짐: apps.js에서 따옴표, 중괄호, 항목 사이 쉼표를 확인하세요.
  • 수정이 안 보임: 저장소의 Actions 탭에서 배포 성공 여부를 확인한 뒤 새로고침하세요.
저장 범위를 알아두세요.

이 보관함은 HTML·CSS·JavaScript 파일을 공개 웹사이트로 배포합니다. Python·PHP 같은 서버 코드는 실행하지 않습니다. 앱 화면에서 입력한 데이터는 GitHub에 자동 저장되지 않습니다. 로그인, 여러 기기의 데이터 동기화, 방문자의 파일 업로드는 별도 서버나 저장 서비스가 필요합니다. 공개할 파일에는 비밀번호나 비밀 API 키를 넣지 마세요.
